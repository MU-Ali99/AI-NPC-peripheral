# v0.3.3 - Input and Cancellation Fixes

- Printable keys stay inside the conversation text box and no longer reach Stardew menu shortcuts.
- `E` can be typed normally without disrupting the input menu.
- `Escape` cancels a request while the NPC is thinking.
- Cancelled replies are discarded instead of appearing later or changing friendship.
- Offline, timeout, and invalid-response errors now have different messages.
- Facial expressions use a neutral display format that avoids awkward grammar.
