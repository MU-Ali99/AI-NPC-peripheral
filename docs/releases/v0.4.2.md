# v0.4.2

This update reduces avoidable CPU inference latency without changing the relationship score rules.

- Preloads the configured Ollama model when NPCBridge starts.
- Keeps the model resident for 30 minutes.
- Reduces recent dialogue history from six completed turns to four.
- Reduces context allocation from 4096 to 3072 tokens.
- Reduces the output budget from 240 to 140 tokens.
- Omits duplicate relationship and custom world data from the model prompt.
- Logs model load, prompt evaluation, generation, token counts, retries, and total time.

A local source-mode test measured 54.6 seconds for a cold request and 8.1 seconds for the immediately following warm request. Startup preload moves most of the cold cost before the player begins a conversation.
