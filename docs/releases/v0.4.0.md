# v0.4.0

This release separates language judgment from state management.

The local model writes the NPC reply, facial expression, and a POSITIVE, NEUTRAL, or NEGATIVE judgment for the current message. NPCBridge applies configurable +10, 0, or -10 changes to its persistent 0–1000 relationship score.

SQLite stores full completed turns and supplies the six most recent conversations to the next prompt. Every request has a lifecycle status. Duplicate IDs, cancellation, failed generation, and stale concurrent results cannot update the relationship.

The Stardew adapter remains thin: it gathers game context, sends a request ID, supports cancellation, displays the result, and applies the returned delta to Stardew friendship points.

Local comparison selected `gemma3:4b` over `qwen2.5:3b`. Gemma was slower on CPU but produced much more natural character dialogue in representative insult, threat, prompt-attack, relationship, and Abigail cases.
