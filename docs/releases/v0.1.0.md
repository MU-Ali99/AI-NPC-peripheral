# v0.1.0 — First Working Prototype

Released locally: 2026-08-15  
Git tag: `v0.1.0`  
Commit: `e2d8869`

## Proven workflow

The first working version established this local text-to-text path:

```text
Stardew Valley
  -> Stardew AI mod on SMAPI
  -> HTTP/JSON conversation request
  -> NPCBridge 0.1.0
  -> Ollama / local model
  -> NPCBridge response
  -> Stardew dialogue box
```

## Included functionality

- Separate Stardew game adapter and standalone NPCBridge process.
- Asynchronous HTTP so model generation does not block Stardew's main thread.
- Nearest-villager detection and custom text-entry menu.
- Player, NPC, friendship, location, season, day, time, and weather context.
- External original profiles for Abigail and Linus.
- Replaceable LLM backend interface with Ollama as the first implementation.
- Versioned conversation endpoint, request validation, safe error handling, and logging.
- Python source workflow and packaged `NPCBridge.exe` workflow.
- Automated API tests and live bridge-to-Ollama verification.
- Successful SMAPI title-screen load verification with the mod installed.

## Environment

- Game: Stardew Valley
- Mod loader: SMAPI
- Python
- Ollama
- Model: `qwen2.5:1.5b`
- Operating system: Windows 11

## Known limitations

- Text-only interaction.
- Abigail and Linus profiles only.
- No session memory, voice, generated quests, or autonomous behavior.
- NPCBridge protocol still contains some Stardew-specific assumptions scheduled for a later refactor.
- Full in-save player-controlled acceptance testing remains manual.
- The original v0.1.0 hotkey was `Alt+1`; v0.1.1 changes it to `Alt+0`.
