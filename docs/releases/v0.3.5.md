# v0.3.5 - Insult Response Quality Gate

NPCs no longer respond to direct insults by comforting or counseling the player. Offers of tea, rest, quiet time, and similar soothing language are rejected when they appear in an insult response. Repeated failures use the character-specific firm fallback.

Direct insults also cannot be copied back verbatim, which prevents the model from accidentally applying the player's description to the wrong person.
