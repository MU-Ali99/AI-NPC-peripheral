# v0.2.1 - Character Voice Update

Character profiles now control more than a list of personality traits. Each profile can define:

- speech cadence
- characteristic vocabulary
- verbal habits
- phrases and styles to avoid
- reactions to greetings, insults, technical questions, and other situations

PersonaEngine labels direct insults and prompt-injection attempts before generation so the model understands who the remark targets. Responses containing common assistant, counselor, disclosure, or out-of-character phrases are rejected and retried.

Linus is configured to answer rudeness with brief firmness or dry humor. Abigail is more energetic, sarcastic, and confrontational. These rules remain profile data rather than character-specific branches in the bridge core.

Sixteen automated tests pass, including checks that each profile contributes different speech guidance and that insults are classified as directed interactions.
