# v0.3.1 - Cleaner Character Reactions

- Removed body-language narration from generated dialogue.
- Facial expressions are now short, specific phrases instead of neutral placeholders.
- Direct insults must be confronted in the character's own voice rather than brushed aside with generic politeness.
- Dialogue may run up to 800 characters when the subject needs a fuller answer.
- Simple exchanges can still remain short and natural.
