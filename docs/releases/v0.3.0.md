# v0.3.0 - Relationship Memory

Conversations now leave a mark instead of disappearing after the dialogue box closes.

- Stores compact interaction history separately for every player and NPC.
- Gives sincere compliments a small friendship boost.
- Reduces that boost when compliments are repeated and makes excessive praise uncomfortable.
- Remembers insults and hostility, allowing characters to become wary or hold a grudge.
- Sends a bounded friendship-point change back to the Stardew adapter.
- Shows a short facial expression and body-language cue before each spoken reply.

Memory is stored locally in `data/npcbridge.db`. It records interaction categories, friendship changes, and short message excerpts; it does not store model prompts or full responses.
